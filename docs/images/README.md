# Screenshot provenance

The screenshots in this directory were captured from the actual DomusMatchAI interface running `npm run demo` in a browser. They are not design mockups or generated images.

- `clients.png`: fictional requests and the client archive.
- `properties.png`: fictional property records.
- `matching.png`: the real local matching engine applied to a fictional client request.

Fixtures live in `src/demo.js`. Names, addresses and records are invented; email addresses use `example.com`, and phone fields are not real numbers. The visible demo banner is retained. No production Firebase project or agency database was used.

`icon.svg` is an original vector asset created for this public edition. Desktop icons are generated from it with `npx tauri icon docs/images/icon.svg`.
